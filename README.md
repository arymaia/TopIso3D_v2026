# TopIso3D v2026

TopIso3D is a tool for **topological analysis and visualization of electronic density** from CRYSTAL outputs.
It provides an intuitive graphical interface to explore critical points, bond paths, and topological isosurfaces.

---

## 🔍 Overview

TopIso3D was developed to facilitate the analysis of quantum chemical topology, particularly in systems computed with the CRYSTAL code.

Main features include:

* Visualization of:

  * Nuclear Attractors (NAs)
  * Bond Critical Points (BCPs)
  * Ring Critical Points (RCPs)
  * Cage Critical Points (CCPs)
* Bond path plotting (including dotted representation)
* Topological isosurface rendering
* Integration with TRHO and related outputs
* Interactive visualization using Plotly

---

## 🧰 Requirements

* Python 3.8+
* Recommended libraries:

  * numpy
  * matplotlib
  * plotly
  * tkinter (usually included with Python)

If needed, install dependencies with:

```bash
pip install numpy matplotlib plotly
```

---

## 🚀 How to Run

From the project directory:

```bash
python topiso3d_v2026.py
```

This will open the graphical interface.

---

## 📂 Input Files

TopIso3D is designed to work with output files generated by CRYSTAL calculations, such as:

* `.out`
* `.DAT`
* TRHO-related outputs

Make sure the files are complete and correctly formatted.

---

## 🖥️ Features in the GUI

* Selection of critical points to visualize
* Adjustable visualization options (size, grouping, labeling)
* Bond path plotting controls
* Isosurface visualization tools
* Interactive 3D rendering (Plotly)
