# TopIso3D v2026

![TopIso3D Interface](docs/images/interface.png)

**TopIso3D v2026** is a cross-platform environment for the management,
execution, organization, visualization, and exploration of topological
analyses based on CRYSTAL/TOPOND calculations.

It provides an integrated graphical environment that connects TOPOND
calculations with structured scientific workflows for the analysis and
exploration of topological data.

## Features

- Execution and management of TRHO, TLAP, and ATBP calculations
- Structured organization and parsing of TOPOND results
- Interactive visualization of critical points and bond paths
- Exploration of electron-density and Laplacian critical points
- BCP distance analysis
- Comparative evaluation of BCP topological descriptors
- Preparation and execution of PL2D campaigns
- Interactive visualization of PL2D isosurfaces
- Report generation
- Data export to Excel and CSV
- Cross-platform support for Windows, macOS, and Linux
